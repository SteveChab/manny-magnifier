# CLAUDE.md — agent notes for mmagnifier

## Repo orientation

- `app/index.html` — the web app (camera, filters, controls). Single-file vanilla HTML/CSS/JS, no build step.
- `native/` — Capacitor wrapper for the paid iOS/Android apps. `native/www/` is auto-generated by `npm run sync`.
- `index.html`, `privacy/`, `css/`, `js/` — the marketing landing page served at mmagnifier.com.
- `tests/` — WebDriverIO + Mocha end-to-end suite that drives the Android Capacitor build via Appium.

- `docs/adr/` — decisions that are expensive to rediscover. Read the relevant record before
  "cleaning up" anything it covers (no `sepia()`, canvas-as-display-layer, exact version pins,
  three-layer camera recovery).
- `.claude/skills/mmagnifier-engineering-health-check/` — the pre-flight risk gate. Run it before
  touching code.

Architecture detail lives in `README.md`. Don't duplicate it here.

## Toolchain floor

```bash
cd native && nvm use    # .nvmrc pins Node 24; the Capacitor 8 CLI hard-fails on Node 20
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"   # system default is Java 8
```

Android is compileSdk/targetSdk 36, minSdk 24. targetSdk 36 is a Google Play requirement for new
apps as of 31 Aug 2026 — never lower it. Dependency versions in `native/package.json` are pinned
exactly on purpose; see `docs/adr/0004`.

## Test-after-change contract

When you modify `app/index.html` or anything under `native/`, run the suite before considering the change done:

```bash
cd native && nvm use                 # .nvmrc pins Node 24; the CLI hard-fails on Node 20
npm run sync                         # copy app/ into native/www/, then cap sync
# rebuild + install debug APK in Android Studio
cd ../tests && npm test             # ~2–3 min on a USB-attached Android device
```

The suite was added specifically to guard against regressions in color modes, contrast cycling, zoom, pause/resume + draw-loop behavior, native button visibility, OCR reentrancy, and localStorage persistence — all areas where bugs have shipped before. Don't skip.

Manual-only checks (camera live image, torch LED, OCR accuracy, TTS audio) are listed in `TESTING.md`; flag them to the user when relevant.
